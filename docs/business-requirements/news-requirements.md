# News Business Requirements

## Overview
Определяет функциональность страницы "Новости" — основного раздела сайта, через который посетители получают актуальную информацию о деятельности экологического движения.

## Functional Requirements

### FR-N-01: Отображение ленты новостей
- На странице отображается список всех новостей
- Новости отображаются в порядке убывания даты (сначала новые)
- Каждая новость отображается целиком (без превью) и содержит:
  - Заголовок
  - Полное содержание
  - Дату публикации
  - одну и строго одну картинку вверху новости

### FR-N-02: Фиксированная шапка
- При прокрутке страницы новостей шапка сайта ("Эковеды" + меню) всегда остаётся вверху экрана
- Шапка не уходит под скролл и всегда видна пользователю

### FR-N-03: Пагинация / Бесконечная лента
- По умолчанию показывается ограниченное количество новостей на одной странице
- Доступен механизм подгрузки дополнительных новостей - бесконечная прокрутка

## Сущность "новость"

| Поле | Описание |
|------|----------|
| Заголовок | Название новости |
| Содержание | Полное текстовое содержание новости |
| Дата публикации | Дата и время создания новости |
| Картинка | Одно изображение, связанное с новостью (обязательное поле) |
