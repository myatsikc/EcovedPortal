# Common Business Requirements

## Overview
Определяет общие элементы интерфейса сайта EcovedPortal: шапку (логотип) и главную навигацию. Эти элементы присутствуют на всех страницах сайта и обеспечивают базовую структуру пользовательского опыта.

## Functional Requirements

### FR-C-01: Шапка сайта (Header)
- В верхней части каждой страницы отображается строка "Эковеды"
- Слово "Эко" выделено зелёным цветом
- Слово "веды" выделено чёрным цветом
- Весь текст выполнен жирным шрифтом

### FR-C-02: Главное меню
- Содержит два пункта: "Новости" и "О команде"
- Меню расположено под шапкой или рядом с ней (зависит от дизайна)
- Пункт "Новости" выделен как активный при загрузке сайта

### FR-C-03: Поведение по умолчанию
- При открытии сайта автоматически отображается страница "Новости"
- Пользователь может переключиться на страницу "О команде" в любой момент

## Acceptance Criteria
- [ ] Шапка отображается на всех страницах сайта
- [ ] Цветовая схема логотипа соответствует описанию (зелёный "Эко", чёрное "веды")
- [ ] Главное меню содержит ровно два пункта: "Новости" и "О команде"
- [ ] При первом открытии сайта пользователь видит страницу "Новости"
- [ ] Переключение между разделами работает без перезагрузки страницы
