# Common Technical Specification

## Overview
Техническая спецификация для общих элементов портала EcovedPortal: шапка (header), навигационное меню, корневой layout и страница документации API.

---

## Component Architecture (Фронтенд)

**Стек:** Next.js (App Router) + TypeScript + Material UI (MUI)

### Структура компонентов

```
src/
├── app/
│   ├── layout.tsx              # Корневой layout (шапка + контейнер)
│   └── api-docs/
│       └── page.tsx            # Страница документации API
├── components/
│   ├── header/
│   │   ├── header.tsx          # Шапка "Эковеды"
│   │   └── nav-menu.tsx        # Меню: Новости / О команде
│   └── shared/
│       └── container.tsx       # Общий контейнер для контента
```

### Компоненты

#### 1. Header (`components/header/header.tsx`)

- Отображает текст "Эковеды"
- "Эко" — зелёный цвет (`#4CAF50` или из темы MUI `theme.palette.success.main`)
- "веды" — чёрный цвет
- Жирный шрифт (`fontWeight: 'bold'`)
- **Фиксация:** `position: sticky` для фиксации при скролле страницы
- Высота: ~60-70px
- Расположен в верхней части экрана, не уходит под скролл

#### 2. NavMenu (`components/header/nav-menu.tsx`)

- Два пункта меню:
  - **"Новости"** — активный по умолчанию (ссылка на `/`)
  - **"О команде"** — неактивный (ссылка на `/team`)
- Стилизация активного пункта: выделение цветом (зелёный) и жирностью
- Расположен под шапкой или рядом с ней (зависит от дизайна)

#### 3. Root Layout (`app/layout.tsx`)

- Обёртывает все страницы сайта
- Содержит:
  - Компонент Header (всегда виден)
  - Компонент NavMenu (всегда виден)
  - Контейнер для контента (`<Container>`)
- Настраивает глобальные стили (шрифты, цвета из MUI темы)

#### 4. Shared Container (`components/shared/container.tsx`)

- Обёртка для контента каждой страницы
- Ограничивает максимальную ширину контента
- Центрирует контент на экране
- Отступы сверху: ~20px (после шапки)

#### 5. API Docs Page (`app/api-docs/page.tsx`)

- Страница с описанием API эндпоинтов
- Содержит:
  - Заголовок "API документация"
  - Ссылку на Swagger UI: `[Открыть Swagger UI]` → `http://localhost:8000/docs`
  - Краткое описание эндпоинта `GET /api/news` (см. news-spec.md)

---

## Pages Map

| Страница | Путь | Описание |
|----------|------|----------|
| Корневой layout | `_` | Шапка + меню + контейнер для всех страниц |
| API документация | `/api-docs` | Ссылка на Swagger UI + описание эндпоинтов |

---

## Data Flow

```
1. Пользователь открывает любой URL сайта
        │
        ▼
2. Next.js рендерит app/layout.tsx
        │
        ▼
3. В layout.tsx рендерится Header + NavMenu
        │
        ▼
4. NavMenu определяет активный пункт по текущему URL
        │
        ▼
5. Контент страницы рендерится внутри Container
```
