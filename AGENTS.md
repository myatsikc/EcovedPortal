# Инструкции для ИИ-агентов (EcovedPortal)

## Справочная информация
- **Проект:** EcovedPortal
- **Язык разработки:** Python.
- **Команда:** Один разработчик.
- **Задача:** Создание сайта с базой данных и админкой.
- **Среда разработки:** PyCharm.
- **Архитектура развертывания:** Два контейнера (один для бэкенда, один для фронтенда).

## Фронтенд стек
- **Фреймворк:** Next.js (React).
- **Язык:** TypeScript.
- **UI Библиотека:** Material UI (MUI) — набор готовых пользовательских элементов.
- **Инструменты:** Визуальное редактирование интерфейса через React Designer.
